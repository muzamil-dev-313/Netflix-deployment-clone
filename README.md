# Netflix UI Clone

## Educational Project Notice

This project is a frontend Netflix-inspired UI clone created with HTML and CSS for learning web development concepts and responsive design.

## Features

* Responsive Netflix-inspired user interface
* Modern landing page layout
* Navigation bar
* Hero section
* Movie and TV show content cards
* Footer section
* Pure HTML and CSS implementation

## Technologies Used

* HTML5
* CSS3

## Learning Objectives

This project was built to practice:

* HTML page structure
* CSS styling techniques
* Flexbox and Grid layouts
* Responsive web design
* UI recreation and frontend development skills
